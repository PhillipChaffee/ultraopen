# ultraopen

Deterministic multi-agent workflow orchestration and an `ultracode` effort mode for [opencode](https://github.com/anomalyco/opencode).

Status: in development. See the milestone plan for scope.

## Development

```bash
bun install
bun run check      # lint + typecheck + tests (95% coverage gate) + Node parity
bun run m0         # provider smoke test against a live model
```
